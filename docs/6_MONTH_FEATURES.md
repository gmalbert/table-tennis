# Pong Odds — 6-Month Feature Roadmap

## Month 1: Match Day

- **Today's fixtures** — All upcoming WTT/ITTF matches with model win probabilities and DraftKings odds.
- **Tournament context badge** — Grand Smash, World Tour, Challenger — displayed on each match card.
- **Live score ticker** — Auto-refreshing scores during Grand Smash and World Tour events.
- **Best bet of the day** — Highlighted pick with highest edge.

## Month 2: Player Pages

- **Player profile** — Elo rating history chart, recent results, H2H vs. top opponents.
- **Style indicator** — Attacking, defensive, or all-round classification.
- **National team record** — World Championships and Olympics performance.

## Month 3: Betting Tools

- **Value finder** — Filter matches where model edge vs. DraftKings exceeds 3%.
- **Odds tracker** — Opening vs. current DraftKings lines for this week's events.
- **Parlay builder** — Multi-match parlay probability calculator.

## Month 4: Tournament Brackets

- **Bracket viewer** — Visual bracket for WTT Grand Smash events.
- **Champion probability** — Model win probability to reach each round and win the tournament.
- **Upset tracker** — Historically how often each seed line upsets the higher seed.

## Month 5: Historical Analysis

- **Model accuracy report** — Accuracy by tournament tier and match type.
- **Player form tracker** — Rolling 3-month win rate chart for top-50 players.
- **Elo leaderboard** — Real-time Elo rankings vs. ITTF official rankings.

## Month 6: Automation

- **Event-week email** — Preview of upcoming Grand Smash with top picks.
- **Nightly data refresh** — GitHub Action fetches new results and odds.
- **Discord picks** — Post top daily pick to Discord webhook.
